language reference

    
Prefix notation: the operator comes first. Everything is an expression. Only mittha and nil are falsy — 0 and "" are truthy. Comments run to end of line with ;.

    

      
(jog 1 2 3)arithmetic, prefix (also biyog gun vag vagshesh)

      
(deo x 5)bind a value

      
(deokaj f [x] ...)define a function

      
(kaj [x] ...)anonymous function (lambda)

      
(jodi test then else)conditional

      
(dhoro [x 1 y 2] ...)local bindings

      
(kor a b c)sequence; returns the last value

      
(bolo x)  or  'xdata literal (unevaluated)

      
(rupantor f lst)apply f to each element

      
(beche p lst)keep elements where p is truthy

      
(milao f init lst)fold left

      
nil  sotyo  mitthaliterals (nil = the empty list)
